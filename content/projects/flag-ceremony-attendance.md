## Overview

This project was developed for a college subject at the **College of Computer Science**. It replaces manual attendance tracking during **flag raising ceremonies** with a dedicated mobile application.

## My Contributions

I was the **sole developer** and **team lead** for our group. I built the entire mobile app using **TypeScript**, **Expo**, and **React Native**.

## Key Features

- Student attendance recording for flag ceremonies
- Mobile-first workflow for staff and administrators
- Built with Expo for cross-platform mobile development

- Applied mobile development skills to a real campus workflow
- Led the team while owning all technical implementation
