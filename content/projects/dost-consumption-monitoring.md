## Overview

This system was built during my **internship at DOST Region I**. It helps the agency monitor monthly **electricity** and **fuel** consumption — a practical operational tool rather than a classroom demo.

## My Contributions

I served as **project manager** and **lead developer**, coordinating deliverables while building the application on the **PERN stack**. I also handled **Docker** setup for deployment so the system could run consistently in the agency environment.

## Key Features

- Monthly consumption tracking for electricity and fuel
- Full-stack web application for data entry and review
- Dockerized deployment for production use
