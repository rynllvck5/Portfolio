## Overview

This was a **software + hardware** project for an application development course. The system verifies attendance using **QR codes** and **fingerprint scanning**, connected through **Arduino** and an **Android** application.

## My Contributions

Although it was a group project, I was the **sole developer** and **team lead**. I built the Android app in **Android Studio** using **Kotlin** and integrated the **Arduino** hardware for fingerprint and QR verification.

## Key Features

- QR code-based attendance check-in
- Fingerprint verification via hardware module
- Arduino integration with Android application
- Combined embedded and mobile development

## Takeaways

- Gained hands-on experience bridging hardware and software
- Learned to troubleshoot integration between Arduino and mobile apps
- Demonstrated ability to deliver beyond pure web development
