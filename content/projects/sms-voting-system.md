## Overview

This project spans two phases of our **Application Development** course — a **midterm SMS voting system** (`appDevSMSProject`) and an **enhanced final version** (`SMSVotingProject`) with additional features and improvements.

## My Contributions

I was the **sole developer** for both versions. The stack includes **Flutter/Dart** for the application frontend, **PHP** and **MySQL** for the backend, and **Ozeki** technology for SMS gateway integration.

## Evolution: Midterm → Final

| Phase | Focus |
|-------|-------|
| Midterm | Core SMS voting via Ozeki |
| Final | Enhanced features, improved UX, expanded functionality |

## Key Features

- Text-to-vote via SMS using Ozeki gateway
- Flutter mobile application frontend
- PHP/MySQL backend for vote management
- Iterative improvement from midterm to final deliverable

## Takeaways

- Learned to integrate third-party SMS gateway technology
- Practiced iterating on a project across two development phases
- Combined mobile frontend with traditional web backend stack
